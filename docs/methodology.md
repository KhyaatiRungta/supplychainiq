# Methodology

## Approach

1. Acquire the raw DataCo CSV (91 MB, 180,519 rows, 53 columns, Latin-1, LF).
2. Profile schema, nulls, duplicates, dates, distinct values and delivery definitions
   (`scripts/inspect_data.py`, `scripts/validate_data.py`).
3. Clean with a reproducible script (`scripts/prepare_cleaned_data.py`): trim/collapse whitespace,
   parse dates, standardise names, add three derived fields, exclude PII/redundant/empty columns.
   Output `data/processed/cleaned_supply_chain.csv` (180,519 rows, 29 columns).
4. Build the Excel workbook (`excel/supply_chain_analysis.xlsx`) with a cleaned table, data
   dictionary, summaries and KPI sheet.
5. Specify the Power BI model, DAX measures and dashboard pages (`powerbi/dax/measures.dax`,
   `docs/dashboard_design.md`).
6. Analyse four to six evidence-backed findings and limitations
   (`docs/business_insights.md`).
7. Document and (in a full desktop build) capture screenshots.

## Eligibility rule used throughout

- Eligible delivery record: `Delivery Status <> 'Shipping canceled'`.
- Late record: `Delivery Status = 'Late delivery'`.
- Late Delivery Rate = late / eligible.
- Order-profit margin = total profit / total sales (weighted), never the average of row ratios.

## Reproducibility

Run from the project root:

    python3 scripts/prepare_cleaned_data.py
    python3 scripts/validate_data.py
    python3 scripts/inspect_data.py

The Excel workbook is regenerated by `build_excel.py` in the working notes (rerun to change).

## Notes on causation

This project is descriptive analytics. No correlation is presented as causation, no supplier data or
pharmaceutical assumptions are invented, and no predictive model is trained.
